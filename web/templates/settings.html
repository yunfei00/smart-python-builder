Builder 服务

访问地址、主机与文件保留策略。

用于飞书通知中的任务详情、管理员审批等链接。请填写其他设备能够访问 Smart Python Builder 的地址。示例：http://192.168.1.105:8000 或 https://builder.example.com。保存后用于后续通知，无需重启；Listening Host 与 Allowed Hosts 不会随之修改。

允许访问 Builder 的主机地址，多个地址用逗号分隔。例如 localhost,127.0.0.1,192.168.1.100。局域网测试可使用 *；这不是客户端访问权限控制。 构建文件保留多少天后自动清理。以上两项保存后需要重启服务。
